# 假期计算器 · 上四休二

一个单文件网页工具，用来查询「上 4 休 2」排班下的放假安排。打开即用，无需安装任何东西。

## 在线访问

https://851682852.github.io/vacation-calculator/

## 功能

- **今日状态** —— 一眼看到今天上班还是放假，以及本轮还剩几天
- **放假倒计时** —— 距离下次放假还有几天、下次放假是哪两天
- **周期圆点图** —— 当前 6 天周期中，每天是上班还是休息
- **指定日期查询** —— 输入任意日期，判断那天是否放假，以及在周期中的位置
- **撞上周末** —— 自动滚动扫描未来两年，找出「休息日恰好落在周六/周日」的日期，分「完整双休」和「只蹭到一天」两组
- **未来 30 天** —— 逐日列出班休安排，落周末的休息日带角标

## 排班规则

- 基准：2026-10-11 为上班第 1 天
- 周期：连续上 4 天班 + 连续休 2 天，6 天一轮循环
- 暂不含法定节假日与调休

## 修改规则

打开 `index.html`，改文件开头的三个变量即可：

```js
const BASE_DATE = '2026-10-11';  // 已知的「上班第 1 天」
const WORK_DAYS = 4;             // 连续上班天数
const REST_DAYS = 2;             // 连续休息天数
```

比如改成上五休二：`WORK_DAYS = 5`、`REST_DAYS = 2`。

## 本地使用

直接双击 `index.html`，或下载后拖进浏览器。
